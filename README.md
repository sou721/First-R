# 🐶 わんこの気持ち

犬の顔を撮影（または写真を選択）すると、表情から大まかな感情を推定する Web アプリです。

## 判定できる感情

😊 うれしい / 😌 リラックス / 🤩 わくわく / 😠 怒り・警戒 / 😨 不安・こわい / 😢 しょんぼり / 😴 ねむい

結果には感情ごとの割合、ひとことメッセージ、接し方のアドバイスが表示されます。
犬がはっきり写っていない場合は撮り直しを促します。

## しくみ

- [Transformers.js](https://huggingface.co/docs/transformers.js) で画像とテキストの対応を学習した CLIP モデル（`Xenova/clip-vit-base-patch32`）をブラウザ内で動かし、「笑っている犬」「歯をむき出して怒っている犬」などの説明文との近さで分類します（ゼロショット分類）。
- 1 つの感情に複数の説明文を用意してスコアを合算しています。説明文は `emotions.js` で編集できます。
- 画像は端末内だけで処理され、サーバーには送信されません。初回のみモデル（約 150MB）をダウンロードし、以降はブラウザにキャッシュされます。

## 使い方

ビルド不要の静的サイトです。任意の静的サーバーで配信してください。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

スマホのカメラを使うには HTTPS が必要です（GitHub Pages などで公開すると簡単です）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | スタイル（ダークモード対応） |
| `app.js` | カメラ撮影・モデル読み込み・判定・結果表示 |
| `emotions.js` | 感情の定義と分類用の説明文、スコア集計 |

## 注意

表情だけからの推定なので、結果はあくまで目安です。しっぽや体の姿勢、状況もあわせて判断してください。
