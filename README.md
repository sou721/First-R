# First-R：ケッペン気候区分クイズ

高校地理の定期テスト対策用の、ケッペンの気候区分の問題アプリです（Python / Flask）。

## 機能

- **クイズ（4択）**：出題タイプと問題数（5・10・20問）を選べます
  - 雨温図から判定：都市名を伏せた雨温図を見て気候区を答える
  - 都市の気候区：「ロンドンの気候区は？」など
  - 特徴から気候区：植生・土壌・分布などのヒントから答える
  - 用語・基準の知識：セルバ、ラトソル、18℃・−3℃・10℃・22℃ の基準 など（30問）
  - ミックス：上記すべて
- **解説**：解答後に、最暖月・乾燥限界・最寒月…と順を追った「判定の手順」を表示
- **結果画面**：正答率と、間違えた問題の見直し
- **まとめ**：13の気候区（Af, Am, Aw, BS, BW, Cs, Cw, Cfa, Cfb, Df, Dw, ET, EF）の一覧表と、代表21都市の雨温図
- **判定ツール**：12か月の気温・降水量を入力すると気候区と判定の手順を表示

## 起動方法

```bash
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。解答は数字キー 1〜4 でも選べます。

## テスト

```bash
python -m pytest
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `koppen_quiz/koppen.py` | 気候区の判定ロジック（教科書のフローチャート準拠） |
| `koppen_quiz/data.py` | 気候区の解説・都市の気候データ・知識問題 |
| `koppen_quiz/quiz.py` | 問題の生成と表示データの組み立て |
| `koppen_quiz/climograph.py` | 雨温図の SVG 生成 |
| `koppen_quiz/app.py` | Flask のルーティング |

都市の気候データは学習用のおおよその平年値です。問題を増やすときは `data.py` の `CITIES` や `KNOWLEDGE` に追加してください（都市データは `tests/` で判定結果が検証されます）。
